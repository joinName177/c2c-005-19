# 有效声音判定方案（情绪分析前置闸门）

## 问题

整段静音也会算出一组情绪标签和百分比。固定音量门槛会被不同设备的录音增益误伤
（轻声被当静音）；只随背景抬门槛会把持续底噪当讲话（AGC 把底噪抬高后门槛跟着抬）；
单次响声也可能被当一句人声。

## 判定方式：三道证据组合（而非单一门槛）

判定在 `src/core/voice-detector.ts`，是不依赖浏览器 API 的纯函数，
输入单声道 PCM（采样率来自解码结果），逐帧计算：

1. **取样范围与分帧**
   - 对裁剪后的完整片段（≤10 秒）逐帧分析，不挑片段。
   - 帧长 30 ms、帧移 10 ms（48 kHz 下 1440/480 采样点）。
   - 帧能量 = 帧内 RMS，统一换算 dBFS。
2. **本底噪声基线（自适应，但不被语音污染）**
   - 全部帧能量排序，取第 20 百分位作为本底噪声 `floorDb`（语音占多数时，
     低分位仍落在停顿/间隙上）；
   - 再取“贴近本底”的帧（≤ floorDb + 6 dB）重新求第 20 百分位迭代一次，
     避免语音占满时基线被抬高；
   - 叠加绝对地板 −60 dBFS：`gateDb = min(floorDb + 9, −45 dBFS)`。
     −45 dBFS 的绝对上限保证 AGC 把本底噪声抬到 −35 dBFS 时，
     持续噪声即使整体超出门槛，仍会被第三道证据否决。
3. **能量存在**：帧 RMS ≥ gateDb 记为“有声帧”。
4. **时间结构（否决持续噪声）**：有声帧按“间隙 ≤ 120 ms 合并”成声段，
   声段内帧能量第 90 与第 10 百分位差（调制深度）需落在 5~25 dB 之间。
   持续风扇/空调/电流声能量稳定、没有音节起伏（< 5 dB），被否决。
5. **瞬态结构（否决单次响声）**：合并后若声段调制深度 > 25 dB
   （碰撞/敲击在百毫秒内指数衰减，能量落差 ≥ 30 dB），或只有 1 个
   时长 < 300 ms 的声段，判为单次响声，不足以分析情绪。

### 有效结论的必要条件（全部满足）

- 有声段（通过调制检验）累计时长 ≥ 400 ms；
- 有声帧占比 ≥ 8%；
- 至少 1 个声段达到 300 ms，或 ≥ 2 个声段（说明是连续发声而非单次瞬态）。

### 阈值依据

| 阈值 | 值 | 依据 |
 | --- | --- | --- |
| 帧长 / 帧移 | 30 / 10 ms | 语音短时分析常用窗，音节级起伏不会被平均掉 |
| 噪声基线百分位 | P20，迭代 1 次 | 停顿帧始终存在；只取近底帧避免被语音抬底 |
| 自适应余量 | +9 dB | 约 2.8 倍本底 RMS，轻声（高于本底 10~20 dB）可越过 |
| 绝对地板 | gate ≤ −45 dBFS | 典型设备底噪 −55 ~ −40 dBFS，正常耳语 > −40 dBFS；防止 AGC 抬底后门槛失控 |
| 段合并间隙 | 120 ms | 音节间短停顿属于同一句话；词间停顿仍被切开并计入停顿统计 |
| 调制深度 | 5~25 dB（P90−P10） | 语音音节强弱起伏通常 6~22 dB；稳态噪声 < 5 dB；碰撞/敲击衰减 > 25 dB |
| 最短有效时长 | 400 ms | 少于约 2 个音节无法支撑四类情绪的特征区分 |
| 最小有声占比 | 8% | 10 秒片段约 0.8 秒，防止极短夹生输入 |

### 无法可靠分析的原因（reason 码 → 中文文案）

- `silence`：全程接近静音，没有可用声音；
- `noise_floor`：只有持续且平稳的背景噪声，缺少人声声调起伏；
- `transient`：只有一次短促响声，像敲击或碰撞；
- `too_short`：说话时间过短（不足 0.4 秒），无法判断情绪。

另给非否决性警告 `clipping`（≥1% 采样点到 ±0.99），提示可能爆音。

### 四类输入的误判对照

| 输入 | 帧能量形态 | 判定结果 |
 | --- | --- | --- |
| 轻声说话 | 高于本底 10~20 dB、有音节调制、多段 | ✅ 有效，自适应门槛放行 |
| 持续底噪（含 AGC 抬高） | 超自适应门槛但调制 < 5 dB | ❌ `noise_floor`，绝对地板 + 调制双重否决 |
| 单次响声 | 单段且 < 300 ms | ❌ `transient` |
| 正常说话 | 明显高于本底、调制深、时长充足 | ✅ 有效 |

### 稳定性

算法只做分帧、排序与线性插值，不使用随机数和时间；同一段 PCM 重复分析
得到逐位一致的结果（临界输入重复分析稳定）。

## 有效时才计算情绪特征

通过判定后，RMS、动态范围、过零率等特征只在**有声帧**上统计，停顿比例取自
真实停顿统计，避免大段静音稀释特征；未通过判定时不运行情绪匹配，
界面不显示自动百分比。

## 状态与来源

情绪结论分三种来源，作品保存后重开仍可区分：

- `auto`：自动建议（含置信度百分比）；
- `manual`：用户明确选择（不显示自动百分比）；
- 无有效结论：显示有效时长、停顿、原因，用户仍可手选标签，保存为 `manual`。

重录 / 重新导入 / 重新分析时，旧的评估结果、警告与依据随音频版本一起重置。
